⚡ INSTALLATION ULTRA-RAPIDE (5 ÉTAPES)
═══════════════════════════════════════════════════════════════════════════

┌───────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 1 : ARDUINO (10 min)                                           │
└───────────────────────────────────────────────────────────────────────┘

  1. Installer bibliothèque DHT (Adafruit) dans Arduino IDE
  2. Câbler DHT11 : VCC→5V, GND→GND, DATA→Pin3
  3. Téléverser "arduino_dht11_code.ino"
  4. Tester moniteur série (9600 bauds)


┌───────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 2 : COMPILER (5 min)                                           │
└───────────────────────────────────────────────────────────────────────┘

  1. Ouvrir CMakeLists.txt dans Qt Creator
  2. Configurer le projet
  3. Compiler (Ctrl+B)


┌───────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 3 : AJOUTER BOUTON (2 min)                                     │
└───────────────────────────────────────────────────────────────────────┘

  Dans mainwindow.cpp (constructeur), ajouter :

  QPushButton *btn = new QPushButton("🔌 Arduino Smart");
  btn->setStyleSheet("background: #1565c0; color: white; padding: 12px;");
  connect(btn, &QPushButton::clicked, this, &MainWindow::ouvrirModuleArduino);
  // Ajouter btn à votre layout


┌───────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 4 : TESTER (3 min)                                             │
└───────────────────────────────────────────────────────────────────────┘

  1. Lancer l'application
  2. Cliquer sur "🔌 Arduino Smart"
  3. Sélectionner COM5 (ou autre port)
  4. Cliquer "Connecter"
  5. Vérifier l'affichage des données


┌───────────────────────────────────────────────────────────────────────┐
│ ÉTAPE 5 : VÉRIFIER BDD (1 min)                                       │
└───────────────────────────────────────────────────────────────────────┘

  Après 30 secondes, exécuter :
  
  SELECT * FROM historique_capteur ORDER BY date_mesure DESC;

🆘 PROBLÈMES COURANTS
═══════════════════════════════════════════════════════════════════════════

❌ "Aucun port disponible"
   → Vérifier branchement USB + installer pilotes Arduino

❌ "Port déjà utilisé"
   → Fermer l'IDE Arduino et le moniteur série

❌ "Erreur compilation Qt5SerialPort not found"
   → Installer Qt SerialPort via Qt Maintenance Tool

❌ "Données corrompues (H:0.00;T:0.00)"
   → Vérifier câblage DHT11 + tester avec un autre capteur
