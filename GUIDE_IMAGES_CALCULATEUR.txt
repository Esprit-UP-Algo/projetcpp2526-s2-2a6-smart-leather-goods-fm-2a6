- .png

- .gif

========================================
COMMENT CRÉER LE DOSSIER IMAGES
========================================

Option 1 - Explorateur Windows:
1. Ouvrir: C:\Users\jkglz\Desktop\projetCPP\
2. Clic droit → Nouveau → Dossier
3. Nommer: images
4. Copier vos images dedans

Option 2 - Ligne de commande:

========================================
VÉRIFICATION
========================================

1. Lancer: build\ProjetCpp.exe
2. Aller dans: Stock → Calculateur
3. Sélectionner un produit
4. L'image doit s'afficher!

Si "Image indisponible":
→ Vérifier que le fichier existe
→ Vérifier le nom (sans accent, avec espace)
→ Vérifier l'extension (.jpg, .webp, etc.)
