✅ BARRE DE NAVIGATION LATÉRALE IMPLÉMENTÉE

La barre de navigation pour le module Arduino Smart est maintenant 
opérationnelle avec 5 sections principales:

   📊 Tableau de Bord    → Vue d'ensemble temps réel
   🔌 Connexion          → Gestion port série Arduino
   📈 Graphiques         → Courbes humidité/température
   📜 Historique         → Base de données complète
   ⚠️ Alertes           → Notifications intelligentes

🚀 COMMENT TESTER

1. Lancer l'application:
   cd build
   ./ProjetCpp.exe

2. Naviguer vers Arduino Smart:
   • Cliquez sur l'onglet "Stock"
   • Cliquez sur le sous-onglet "⚡ Arduino Smart"

3. Tester la navigation:
   • Cliquez sur "📊 Tableau de Bord"
   • Cliquez sur "🔌 Connexion"
   • Cliquez sur "📈 Graphiques"
   • Cliquez sur "📜 Historique"
   • Cliquez sur "⚠️ Alertes"

4. Vérifier les transitions:
   • Les pages changent avec une animation fluide
   • Durée: 300ms avec effet InOutQuad
   • Opacité: 0.0 → 1.0

📋 FONCTIONNALITÉS PAR PAGE

📊 TABLEAU DE BORD
   • Affichage temps réel: Humidité (%) et Température (°C)
   • Barres de progression visuelles
   • Statistiques: min, max, moyenne
   • Nombre de mesures et alertes

🔌 CONNEXION
   • Liste des ports série (COM1, COM4, etc.)
   • Bouton Rafraîchir pour détecter les ports
   • Bouton Connecter/Déconnecter
   • Indicateur de statut (Connecté ✅ / Déconnecté ❌)

📈 GRAPHIQUES
   • Courbe d'humidité (bleu) en temps réel
   • Courbe de température (rouge) en temps réel
   • Historique des 50 dernières mesures
   • Zoom et pan interactifs

📜 HISTORIQUE
   • Table complète des mesures en base Oracle
   • Colonnes: Date/Heure, Humidité, Température, Alerte
   • Filtres par date (début/fin)
   • Export CSV et PDF

⚠️ ALERTES
   • Alertes intelligentes:
     - Humidité < 40% → ⚠️ Trop sec
     - Humidité > 70% → ⚠️ Trop humide
     - Température > 30°C → 🔥 Trop chaud
   • Configuration des seuils personnalisés
   • Historique des alertes
