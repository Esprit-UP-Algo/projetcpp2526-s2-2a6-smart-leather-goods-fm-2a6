┌──────────────────────────────────────────────────────────────────────┐
│                    ⚡ SOLUTION RAPIDE                                │
└──────────────────────────────────────────────────────────────────────┘

   1. Double-cliquer sur:
   
      ┌─────────────────────────────────┐
      │   reconfigurer_qtcreator.bat    │
      └─────────────────────────────────┘
   
   2. Attendre la fin
   
   3. Fermer Qt Creator complètement
   
   4. Rouvrir Qt Creator
   
   5. Fichier → Ouvrir un fichier ou projet
   
   6. Sélectionner CMakeLists.txt
   
   7. ✓ Le projet devrait être configuré!


┌──────────────────────────────────────────────────────────────────────┐
│                  🔄 SOLUTION MANUELLE                                │
└──────────────────────────────────────────────────────────────────────┘

   Dans Qt Creator:
   
   1. Projets (icône clé à molette à gauche)
   
   2. Build Settings
   
   3. Cliquer sur "Re-configure with Initial Parameters"
   
   4. Ou supprimer le dossier build et reconfigurer
