❌ PROBLÈME INITIAL

Dans le module Ravitaillement, section "Aperçu matière sélectionnée":
- Message affiché: "Image indisponible"
- Les 3 types de cuir (Vachette/Agneau/Veau) ne montraient pas d'image
- Légende affichée mais pas de photo

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🔍 CAUSES IDENTIFIÉES

1. TYPO DANS LE CODE
   ❌ Ligne 14053: chemin = ":/pi veau.jpg";
   ✅ Corrigé:     chemin = ":/pic veau.jpg";
   
   Le "c" manquait dans "pic" !

2. MÉTHODE DE CHARGEMENT INADAPTÉE
   ❌ Ancien: QPixmap pix(chemin);
   ✅ Nouveau: const QPixmap pix = loadIllustrationImage(chemin, alts);
   
   La fonction helper cherche dans plusieurs emplacements

3. NOM DE FICHIER DIFFÉRENT
   ❌ Code cherchait: "pic veau.jpg"
   ✅ Fichier réel:   "cuir veau.jpg"
   
   Solution: Ajout de noms alternatifs

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ CORRECTIONS APPLIQUÉES

1. TYPO CORRIGÉE
   ":/pi veau.jpg" → ":/pic veau.jpg"

2. FONCTION HELPER UTILISÉE
   loadIllustrationImage() au lieu de QPixmap direct
   
   Avantages:
   - Cherche dans ressources Qt (:/...)
   - Cherche sur disque (images/, racine, build/..)
   - Supporte noms alternatifs
   - Gestion d'erreur améliorée

3. NOMS ALTERNATIFS AJOUTÉS
   Pour chaque type de cuir:
   
   Cuir Vachette:
   - pic vachette.jpg
   - pic_vachette.jpg
   - cuir vachette.jpg
   - cuir_vachette.jpg
   - vachette.jpg
   
   Cuir Agneau:
   - pic agneau.jpg
   - pic_agneau.jpg
   - cuir agneau.jpg
   - cuir_agneau.jpg
   - agneau.jpg
   
   Cuir Veau:
   - pic veau.jpg
   - pic_veau.jpg
   - cuir veau.jpg ← FICHIER RÉEL
   - cuir_veau.jpg
   - veau.jpg

4. SCALING AMÉLIORÉ
   scaledPixmapForLabel() évite les problèmes de taille nulle
